# 题目文档怎么写 & 题库数据长什么样

两件事：Word 文档的排版规范（给 `tools/build_bank.py` 解析用），和生成出来的 JSON 数据格式（给页面读）。

## 一、Word 文档排版规范

### 文件命名

放进 `马原题/`（或用 `-i` 指定的目录），文件名决定它进哪一章：

| 文件名 | 进哪一章 |
| --- | --- |
| `绪论题目.docx` 或 `导论题目.docx` | 导论 |
| `第一章题目.docx` | 第一章 |
| `第二章题目.docx` | 第二章 |

依此类推，支持到第八章。文件名里的空格会被忽略，`~$` 开头的 Word 临时文件会自动跳过。

### 正文格式

每道题三行结构，题号和答案行是解析的锚点：

```
1、马克思主义认识论首要的和基本的观点是：（ ）
A、 实践的观点 B、 唯物论的观点
C、 辩证法的观点 D、 认识是一个过程的观点
答案： A
```

要点：

- 题号行：数字 + `、` 或 `.` 开头，脚本靠它切分题目；
- 选项行：`A、` `B、` `C、` `D、` 开头，一行放几个都行，会自动拆开；
- 答案行：`答案：` 后跟选项字母。
  - 单选写 `答案：C`，多选写 `答案：AC`（顺序无所谓，会自动排序）；
  - 判断/填空式题目不用写选项，直接写 `答案：正确` 或 `答案：错误`；
- 题干、选项、答案必须各自成行；选项可以跨行，但不能和答案挤在同一行。

### 会遇到的坑

- **题号跳号**：脚本会报 `题号有缺口：38`，说明原文档里少了这一题，回去补；
- **不可见字符**：从别处复制粘贴容易带进 Word 私有区字符，脚本会自动清掉；
- **错字**：原稿里的错字可以登记在 `tools/build_bank.py` 的 `TYPO_FIXES` 里，构建时自动修正；
- **解析不了**：如果某题选项号不是连续的 A、B、C、D，脚本会直接报错并指出题号，按上面的格式改一下即可。

## 二、题库数据格式

`tools/build_bank.py` 生成的 `data/question-bank.js` 长这样（`data/demo-bank.js` 是同一格式的示例）：

```js
window.MAYUAN_QUESTION_BANK = {
  "meta": {
    "title": "马克思主义基本原理概论",   // 页面左上角标题
    "subtitle": "期末复习自测",           // 副标题
    "version": "1.0",
    "updated": "2026-10-13",
    "total": 406                          // 总题数
  },
  "chapters": [
    {
      "key": "ch1",                       // 唯一标识，错题本/进度按它存
      "name": "第一章",                    // 章节列表里显示的名字
      "subtitle": "世界的物质性及发展规律",  // 章节副标题
      "source": true,                     // true=来自 Word 文档，false=占位小题
      "questions": [
        {
          "id": "ch1-1",                  // 唯一编号，不要重复
          "num": 1,                       // 原卷题号，答题卡上显示这个
          "type": "single",               // single 单选 | multi 多选 | judge 判断
          "stem": "马克思主义认为哲学是：（ ）",
          "options": ["选项一", "选项二", "选项三", "选项四"],
          "answer": ["B"]                 // 正确选项字母；判断题固定 options 为 ["正确","错误"]
        }
      ]
    }
  ]
};
```

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 全局唯一，建议 `章节key-题号`，进度和错题本靠它关联 |
| `num` | 原卷题号，只影响显示（答题卡格子上的数字） |
| `type` | `single` 单选、`multi` 多选、`judge` 判断，三者渲染和判分逻辑不同 |
| `stem` | 题干纯文本，不写 HTML |
| `options` | 选项文本数组，顺序即 A、B、C、D；**判断题固定写 `["正确","错误"]`** |
| `answer` | 正确选项字母数组，如 `["A"]`、`["A","C"]`、判断题 `["A"]`（表示正确） |

### 手工加题

小改动用不着 Word，直接往 `data/question-bank.js`（你自己的）或 `data/demo-bank.js`（示例）的 `questions` 数组里加一条就行。
注意：下次运行 `tools/build_bank.py` 会覆盖 `data/question-bank.js`，所以长期维护还是建议改 Word 原文。
